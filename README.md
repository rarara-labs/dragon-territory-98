# DRAGON TERRITORY '98 — Dragon Rush Edition v3

GitHub Pages에 그대로 올릴 수 있는 단일 HTML 웹게임입니다.

## v3 변경점
- 일반 드래곤 기본 이동속도 약 30% 상향
- 스테이지 증가에 따른 속도 상승폭 강화
- 방향전환 빈도와 DRAW 중 플레이어 추적 확률 증가
- 랜덤 순간 돌진 빈도/가속 강화
- 원형 뱀 그래픽을 동양 용 느낌의 캐릭터로 변경
  - 뿔
  - 수염
  - 주둥이와 송곳니
  - 눈
  - 등 가시/갈기
  - 비늘 느낌의 몸통
  - 가늘어지는 꼬리
- 보스는 더 큰 자주색 드래곤으로 표현

기존 v2의 아이템, 보스전, 스테이지 맵, BGM, 효과음, 모바일 진동,
반응형 모바일/PC 조작, 로컬 TOP 5 랭킹은 유지했습니다.

## 실행
`index.html`을 브라우저에서 열면 됩니다.

## GitHub Pages 배포
1. 새 GitHub repository 생성
2. `index.html`과 `README.md` 업로드
3. Settings → Pages
4. Deploy from a branch
5. `main` / `/ (root)` 선택 후 Save

서버나 빌드 과정은 필요 없습니다.
